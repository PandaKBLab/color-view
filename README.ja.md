# Color View

### ZMK分割キーボード向け8色Memory LCDモジュール

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

レイヤー、バッテリー、接続状態をカラーで表示。自作キーボードに、自分だけの画面を追加できます。

Color Viewは、自作キーボード向けの1.33インチ、128 × 128ピクセル、8色対応の表示モジュールです。電源、GND、SCK、MOSI、CSの5本でキーボードに接続します。

**販売について：**現在は販売前です。発売時に、このページへ購入先を掲載します。

**公開状況：**本リポジトリはドキュメントの初期版です。独自Helixキーボードとnice!nano v2を組み合わせたColor Viewの実装例はありますが、再利用可能な公開ドライバーパッケージと、そのままビルドできるキーボード別サンプルは、まだ公開していません。

## こんな画面を作れます

- アクティブレイヤー、バッテリー、USB／Bluetooth出力をまとめたステータス画面。
- レイヤーごとの色分けや小さなアイコン。
- キー配置のプレビューと、その側で押されたキーのハイライト。
- オリジナルのロゴや、キー入力をきっかけに動く小さなアニメーション。

これらはファームウェアで実装するレイアウトのアイデアです。表示モジュール自体に内蔵された機能ではありません。Peripheral側で利用できる情報は、キーボード側の状態同期の実装によって異なります。

## 主な仕様

| 項目 | 内容 |
| --- | --- |
| 表示 | 1.33インチ、128 × 128ピクセル |
| 色 | 黒、白、赤、緑、青、シアン、マゼンタ、黄 |
| インターフェース | SPI書き込み：SCK、MOSI、アクティブHighのCS。MISOは不要 |
| リファレンス配線 | 安定化された3.3 V電源と3.3 Vロジック |
| 主な対象 | ZMKを使う自作分割キーボード |
| リファレンスのコントローラー | 独自Helix実装で使用するnice!nano v2 |

3.3 Vの接続は現在のリファレンス構成を示しています。保証動作範囲とモジュールの実測消費電力は、まだ公開していません。組み込む前に[電源と検証に関する注意点](docs/hardware.md#power-and-validation)を確認してください。

## 寸法・取り付け・コネクター

![Color Viewの基板寸法と組み立て厚さ](assets/mechanical/color-view-dimensions.svg)

- **接続方法：**J1は1 × 5、2.54 mmピッチのピンヘッダー用インターフェースです。J2は5ピン、0.50 mmピッチ、下接点のFPCコネクターで、接点部の厚さ0.30 mmのケーブルに対応します。どちらか一方を使用します。
- **基板外形：**4つの取付タブを含めて26.99 × 45.48 mm。タブを取り外して残りの縁を整えた本体の公称寸法は26.99 × 36.34 mmです。
- **取り付け：**取り外せる4つのタブに、M2ねじ用の直径2.20 mmの穴があります。穴の中心間隔は21.00 × 41.19 mmです。
- **厚さ：**基板1.00 mm、部品高さ1.00 mm、画面0.85 mmに加え、基板と画面の間に接着層があります。組み立て後の実厚は3.00 mmで、接着層はこれらの寸法から約0.15 mmと算出しています。
- **保護フィルム：**画面表面には取り外せる保護フィルムがあり、使用前にはがせます。

座標は[寸法と取り付け](docs/mechanical.md)、ピンの向きは[コネクター図](assets/wiring/color-view-connectors.svg)を参照してください。平面寸法はCAD上の公称値です。購入したリビジョンと接続部品に合わせてクリアランスを確保してください。

## 接続前の確認

1. モジュールのリビジョンとコネクターのピン番号を確認します。
2. キーボードで3本の信号GPIOを使用できるか確認します。
3. 配線表に従って接続します。J1とJ2ではピン番号の順序が異なります。
4. Color Viewに対応したドライバーと、キーボードに合う設定を使用します。
5. 色、向き、スリープからの復帰、左右両側の動作を確認します。

Color Viewには対応するカラー表示ドライバーが必要です。汎用のモノクロ用ドライバーを、そのまま使用することはできません。静止画でも、モジュールへの給電中は、対応ドライバーによるバックグラウンドの表示維持処理を継続してください。
