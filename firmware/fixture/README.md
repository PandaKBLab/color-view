# Color View 工装固件

适用于带 UF2 引导程序的 nice!nano v2 和 Color View 单片测试工装上板。

在本分支的 GitHub Actions 打开最近一次成功的 **Build Color View fixture firmware**。下载 **color-view-fixture-nice_nano_v2**，从 ZIP 取出 **color-view-fixture-nice_nano_v2.uf2**。双击主控复位键进入 UF2 模式，把文件复制到主控挂载的磁盘。

## 测试

1. 上电后等蓝灯慢闪。慢闪约 8 秒，屏幕电源关闭。此时放片、压探针或插拔排线。
2. 蓝灯常亮时观看约 14 秒图案。顺序为八色全屏、横竖条纹、棋盘格及反相、边框及方向图。
3. 下一次慢闪时抬起模块并接 FPC。等常亮后看完整一轮，再等慢闪拔排线。
4. 两种接口逐一检测，由操作员判断是否缺色、缺行、缺列或显示异常。换接没完成时等下一轮。

固件上电自动循环。首件须确认模块 VCC 确实在慢闪前断开，以及 1 秒掉电等待对实际模块足够。慢闪时保持工装主控运行，屏幕掉电期间 SPI 信号保持低电平。屏幕上电时每 500 ms 切换一次 VCOM 极性。
